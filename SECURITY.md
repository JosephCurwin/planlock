# Security

Found a way around the guard? Please report it.

- **Private:** email erwinfeld.oss@proton.me, or use GitHub's "Report a vulnerability" on the Security tab.
- **Public:** open an issue if the finding is not exploitable against a running deployment.

Please include the plan, the tool calls the agent made, and what reached the upstream that should not have.
Links or text are preferred over attachments. In scope: anything that executes outside an approved plan, or approves
a plan without the approver token. Out of scope: the limits listed under "Threat model and limits" in the README.
